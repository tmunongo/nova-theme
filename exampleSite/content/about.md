Welcome to the Observatory. This is an example about page demonstrating the clean editorial layout of the Nova Hugo theme.

## Philosophy & Focus

Nova is designed around three core principles:

* **High Readability:** Carefully calibrated typography scale, comfortable line heights, and dark terminal aesthetic.
* **Unified Layout Width:** Header, lists, article prose, tables, and footer all share a consistent container width so there are no jarring width transitions between pages.
* **Zero Bloat:** Minimal JavaScript, lightning-fast rendering, and native Hugo pipes asset pipeline.

## Technical Architecture

The theme utilizes standard Hugo templating features:

* Dynamic tag & year filtering powered by vanilla JavaScript
* Automatic Mermaid diagram detection with dark terminal theme styling
* Reading progress indicator (The Signal Bar)
* Code block copy buttons
* Fully responsive layout with mobile drawer navigation support
