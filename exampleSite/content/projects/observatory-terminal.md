Observatory Terminal (Nova) is a Hugo theme inspired by mission control consoles, aerospace instrumentation, and minimal typography.

## Key Features

* **Unified Reading Width:** 880px max-width consistent across all page types, header, and footer.
* **No Framework Dependencies:** Built with native CSS custom properties and lightweight vanilla JavaScript.
* **Instant Client-Side Filtering:** Tag and year filters update the view in real-time.
* **Mermaid Diagram Support:** Dark-themed diagrams initialized dynamically via CDN.
