Nova Terminal is a Hugo theme inspired by mission control consoles, aerospace instrumentation, and minimal typography.

## Key Features

* **No Framework Dependencies:** Built with native CSS custom properties and lightweight vanilla JavaScript.
* **Instant Client-Side Filtering:** Tag and year filters update the view in real-time.
* **Mermaid Diagram Support:** Diagrams adapt to the selected site theme (dark/light) and are initialized dynamically via CDN.
